GOOD TO KNOW

开始之前，
你可能想了解。

关于系统、账号与模型配置的几个小问题。

前往西牧控制台
支持哪些桌面系统？

当前提供 Windows x64 和 macOS Apple Silicon（M 系列）安装包。本页提供的版本是未签名或未公证的本地测试包。

登录账号后，就能直接使用所有模型吗？

登录用于完成账号认证。开始对话前，还需要按分组选择可用密钥并配置模型。模型的可用性与能力取决于实际接入的服务和配置。

如何查看余额和充值？

在客户端“设置 → 账号与余额”中查看充值余额，金额标注为 USD。点击余额右侧的“充值”按钮，会通过系统浏览器打开充值页面。

项目和会话在哪里管理？

项目与会话在本地工作区中管理。模型调用、账号登录和充值依赖相应的在线服务；调用远端模型时，会向所使用的服务发送完成任务所需的内容。
