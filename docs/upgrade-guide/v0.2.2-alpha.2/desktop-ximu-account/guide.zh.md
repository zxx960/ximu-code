# 桌面账号登录

[English](guide.md) | 中文

## 变更

桌面配置使用西牧管理接口提供邮箱密码登录和充值余额。已有 DeepSeek 账号凭据仍然保留，但不能用于桌面西牧账号登录。账号设置页不显示赠金余额。桌面 Welcome 必须登录账号，不提供 API Key 或跳过入口；配置模型密钥后，退出或账号失效仍返回登录页。桌面引导不再通过 preload 读取模型密钥是否存在。其他配置保留浏览器授权。

## 迁移

桌面端自定义模型 API 使用分组下拉框代替手动显示名称。创建提供商前，选择当前登录账号的分组，其名称会作为提供商显示名称。已有提供商保留已保存的名称。选择分组不会创建模型密钥或改变 API 协议。

选择分组后，从该组的可用 API 密钥中选择一项，无需手动输入密钥。切换分组会清空选择。所选密钥用于模型发现，仅在保存提供商时写入凭据；查询不会创建服务端密钥。

分组没有可用密钥时，点击**重试**旁的**新建密钥**，即可创建一项并刷新列表。这是显式的服务端修改；重新打开或刷新表单不会创建密钥。

1. 在桌面邮箱密码表单中登录，不会保存密码。
2. 私有部署在 `$DSH_HOME/profiles/desktop/cordis.patch.yml` 的 `ximu-account` 条目下设置 `baseURL`，指向 HTTPS 管理接口根地址。
3. 打开设置 → 账号与余额，确认邮箱和充值余额。独立配置的模型 API Key 仍可使用；本次登录不创建模型密钥或推理路由。
